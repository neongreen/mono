## Spacelift 2

Installed `spacectl`, created a key at <https://neongreen.app.spacelift.io/settings/api-keys>.

Added to fnox via `fnox secrets add SPACELIFT_API_KEY_ID <key>`, `fnox secrets add SPACELIFT_API_KEY_SECRET <secret>`.
And the endpoint `fnox secrets add SPACELIFT_API_ENDPOINT https://neongreen.app.spacelift.io`.

Now `fnox exec -- spacectl whoami` works.

Then immediately it turned out `spacectl` can't create stacks.
See <https://github.com/spacelift-io/terraform-provider-spacelift>.

Created a new stack, created a "Context", added `HCLOUD_TOKEN` there and attached the context to the stack.
