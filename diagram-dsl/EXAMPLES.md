# diagram-dsl Examples Gallery

This document showcases all the examples generated by the diagram-dsl library.

## Overview

All examples are generated from JSX code and output as pure SVG. They can be:
- Viewed in any modern browser
- Embedded in documentation
- Converted to PNG/PDF
- Used in presentations

## New: Semantic Components Examples

The library now includes semantic components (Card, Title, Subtitle, Label) that provide professional styling with minimal code. These examples showcase how to create beautiful diagrams quickly.

### 0a. Styled Flowchart (styled-flowchart.svg)

A modern flowchart using semantic components with rich text.

**Size:** ~2 KB  
**Features:** Card components with variants, Title/Subtitle hierarchy, Label text, minimal code

**Code:**
```tsx
<Stack gap={24} padding={40} alignItems="center">
  <Title level={1}>Modern Flowchart</Title>
  <Subtitle>Using semantic components for clean, professional styling</Subtitle>
  
  <Card id="start" variant="primary" width={200} height={80}>
    <Stack gap={6} alignItems="center">
      <Label bold>Start Process</Label>
      <Subtitle>Initialize system</Subtitle>
    </Stack>
  </Card>

  <Card id="process" variant="warning" width={200} height={80}>
    <Stack gap={6} alignItems="center">
      <Label bold>Process Data</Label>
      <Subtitle>Transform inputs</Subtitle>
    </Stack>
  </Card>

  <Card id="end" variant="success" width={200} height={80}>
    <Stack gap={6} alignItems="center">
      <Label bold>Complete</Label>
      <Subtitle>Return results</Subtitle>
    </Stack>
  </Card>

  <Arrow from="start" to="process" color="#1976d2" strokeWidth={2} />
  <Arrow from="process" to="end" color="#388e3c" strokeWidth={2} />
</Stack>
```

**Benefits over manual styling:**
- No need to specify colors, fonts, border radius manually
- Consistent professional look
- Easy to understand semantic markup
- Rich text (title + subtitle) in boxes

## Usage Patterns Demonstrated

### Layout Patterns

1. **Simple Vertical Stack**
   ```tsx
   <Stack gap={20}>
     <Box>...</Box>
     <Box>...</Box>
   </Stack>
   ```

2. **Horizontal Row**
   ```tsx
   <Row gap={15} justifyContent="center">
     <Box>...</Box>
     <Box>...</Box>
     <Box>...</Box>
   </Row>
   ```

3. **Nested Layouts**
   ```tsx
   <Stack>
     <Text>Title</Text>
     <Row>
       <Box>...</Box>
       <Box>...</Box>
     </Row>
   </Stack>
   ```

### Styling Patterns

1. **Color-Coded Boxes**
   ```tsx
   backgroundColor="#e3f2fd"
   borderColor="#1976d2"
   ```

2. **Rounded Corners**
   ```tsx
   borderRadius={8}  // Small radius
   borderRadius={35} // Large radius (pill shape)
   ```

3. **Centered Content**
   ```tsx
   justifyContent="center"
   alignItems="center"
   ```

### Arrow Patterns

1. **Simple Connection**
   ```tsx
   <Arrow from="box1" to="box2" color="#1976d2" />
   ```

2. **Labeled Arrow**
   ```tsx
   <Arrow from="box1" to="box2" label="HTTPS" />
   ```

## Generating Examples

Generate all examples at once:
```bash
npm run examples
```

Or generate individually:
```bash
npm run dev:simple    # Simple box
npm run dev           # Basic examples
npm run dev:advanced  # Advanced examples
```

## Viewing Examples

The generated SVG files can be opened in:
- **Web Browser:** Double-click any `.svg` file
- **VS Code:** Install SVG preview extension
- **Command Line:** `cat examples/simple-box.svg` (shows SVG source)

## Customization

All examples are easily customizable:
- Change colors to match your brand
- Adjust spacing with `gap`, `padding`, `margin`
- Resize boxes with `width`, `height`
- Modify text with `fontSize`, `fontWeight`
- Add more boxes, arrows, or tiers
