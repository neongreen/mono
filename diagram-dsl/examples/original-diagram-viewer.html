Anthropic Original Diagram Replication

"Prompt engineering vs. context engineering"

🎯 This Diagram Replicates the Specific Anthropic Diagram

This is a faithful replication of the original diagram from Anthropic's documentation, demonstrating the comparison between single-turn prompt engineering and multi-turn context engineering for AI agents.

Structural Features Demonstrated:

  • Two-panel comparison - Side-by-side layout
  • Nested boxes - Context windows containing multiple elements
  • Dashed borders - For context window visualization
  • Multiple element types - Speech bubbles, docs, tools, memory files
  • Neural network grid - 3×3 colored circles representing model
  • Custom arrow routing - Specific attachment points
  • Arrow with label - "Curation" arrow between boxes
  • Y-shaped arrow fork - Model to multiple outputs
  • Feedback loop - Tool result back to message history
  • Arrow shortening - Curation arrow stops before target
  • Different text sizes - Headers, labels, content hierarchy
  • Color-coded elements - Blue prompts, green docs, orange tools, purple memory

📚 New Arrow Features Used:

  • fromSide / toSide - Specify which edge to connect to
  • fromOffset / toOffset - Position along edge (for corners)
  • shortenEnd - Arrow stops before reaching target
  • curve="step" - Orthogonal routing for feedback loop
