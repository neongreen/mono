Simple Anthropic-Style Diagram Template

Perfect starting point for your own diagrams

🎯 Key Features

  • Three-column layout: Input → Processing → Output
  • Color-coded clusters: Blue (primary), Orange (accent), Green (success)
  • Professional cards: 2-3 levels of text hierarchy
  • Clear data flow: Solid arrows for main flow, dashed for data access
  • Shared resources: Data layer at bottom
