# Chapter 1: Getting Started

This chapter introduces the basic concepts of the commenting system.

## Simple Paragraphs

This is a simple paragraph. It has a comment link at the end. When you click it, you can see comments from other readers and add your own.

Each paragraph is independent. This means comments on one paragraph don't affect others. You can comment on specific points that interest you.

## Lists

Commenting works with lists too:

- This is the first list item. You can comment on it independently.
- This is the second item. It has its own comment section.
- And this is the third item.

Ordered lists work the same way:

1. First ordered item
2. Second ordered item  
3. Third ordered item

## Code Blocks

Code blocks are also commentable:

```python
def hello_world():
    """A simple function to demonstrate code commenting."""
    print("Hello, World!")
    return True
```

The entire code block acts as one commentable unit. This is useful for discussing the code as a whole.

## Blockquotes

Even blockquotes can have comments:

> This is a blockquote from an important person.
> It spans multiple lines and discusses profound topics.
> People might want to comment on the wisdom contained herein.

## Multiple Paragraphs

Let's add several paragraphs to demonstrate how the system handles lots of content.

Paragraph number one contains important information about the first topic. It's detailed and comprehensive.

Paragraph two builds on the first one. It adds more context and examples.

Paragraph three wraps things up with a conclusion. Notice how each paragraph has its own comment link.

This allows readers to comment on specific parts of your explanation, making feedback more precise and useful.
