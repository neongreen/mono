## Comparing Converters

Each converter produces slightly different output. Compare the PDFs to see which one works best for your use case:

- **Typst**: Modern typography, good for academic papers
- **Prince**: Professional output, excellent CSS support
- **WeasyPrint**: Clean, simple output

## Regenerating Samples

To regenerate all samples, run:
