# Sample Documents

This directory contains sample PDF outputs generated by printpdf from various sources.

## Sample Files

### 1. local-markdown-sample.pdf
- **Source**: sample.md (local Markdown file)
- **Converter**: WeasyPrint
- **Demonstrates**: Basic markdown features including headings, lists, tables, and code blocks

### 2. sample-typst.pdf (if Typst is installed)
- **Source**: sample.md (same as above)
- **Converter**: Typst
- **Demonstrates**: Typst's native rendering with proper Markdown to Typst conversion

### 3. github-golang-readme.pdf
- **Source**: https://github.com/golang/go/blob/master/README.md
- **Converter**: WeasyPrint
- **Demonstrates**: Fetching and converting files from GitHub repositories

### 4. html-readability-sample.pdf
- **Source**: sample.html (local HTML file)
- **Converter**: WeasyPrint
- **Demonstrates**: Extracting main content from HTML using Readability-like algorithm

### 5. printpdf-readme.pdf
- **Source**: ../README.md (printpdf's own documentation)
- **Converter**: WeasyPrint
- **Demonstrates**: Converting the tool's own documentation to PDF

## Source Files

- **sample.md**: Example markdown file with various features
- **sample.html**: Example HTML file with main content and sidebar
- **generate-samples.sh**: Script to regenerate all samples

## Comparing Converters

Different converters produce different output quality:

- **WeasyPrint**: Open-source, clean output, good for documentation (HTML-based rendering)
- **Typst**: Modern typography, excellent for academic papers (native Typst markup, produces professional PDFs)
- **Prince**: Professional output, commercial license required (requires manual installation)

Compare `local-markdown-sample.pdf` (WeasyPrint) with `sample-typst.pdf` (Typst) to see the difference in rendering quality and typography.

## Regenerating Samples

To regenerate all samples, run:

```bash
cd samples
./generate-samples.sh
```

Or manually:

```bash
cd ..
./printpdf -converters weasyprint -o samples samples/sample.md
```
