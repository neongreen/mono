# Sample Document

This is a sample document to demonstrate the PDF conversion capabilities of printpdf.

## Introduction

This tool can convert Markdown documents to PDF using multiple converters:

- Typst
- Prince XML
- WeasyPrint

## Features

### Input Sources

The tool supports multiple input sources:

1. Local Markdown files
2. Remote URLs
3. GitHub files (public and private)
4. Web pages (with Readability)

### Output Formats

All converters produce PDF output, but with different characteristics:

- **Typst**: Modern, clean typography
- **Prince**: Professional, standards-compliant
- **WeasyPrint**: Simple, reliable
